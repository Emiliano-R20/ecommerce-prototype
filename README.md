# E-Commerce Web App

Frontend e-commerce project built using clean HTML5, custom CSS, and vanilla JavaScript. Developed as a hands-on exercise to master core web technologies and responsive design.

---

## Features & Learnings

- [x] **Semantic HTML5:** Structured for accessibility and good web practices.
- [x] **Responsive UI:** Custom CSS styling without external UI frameworks.
- [x] **Vanilla JavaScript:** DOM manipulation and client-side logic from scratch.

---

## Tech Stack

* **HTML5** (Semantic elements)
* **CSS3** (Flexbox/Grid layout)
* **JavaScript** ( DOM Manipulation)
* **Tools:** VS Code (Live Server), Git & GitHub

---

## 💡 About this project
I built this project just to make sure I had rock-solid fundamentals in core web development before moving into full-stack frameworks like React and Node.js.
